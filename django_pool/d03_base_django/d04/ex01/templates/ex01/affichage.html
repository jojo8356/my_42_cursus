Ex01 : Processus d'affichage d'une page statique.

Le processus d'affichage d'une page web statique en Django :

  1. Le client envoie une requête HTTP à l'URL demandée.
  2. Django redirige la requête vers le fichier urls.py qui associe l'URL à une vue.
  3. La vue exécute la logique nécessaire et prépare le contexte.
  4. La vue renderise le template avec le contexte.
  5. Django renvoie une réponse HTTP contenant le HTML généré.
  6. Le navigateur affiche la page au client.
